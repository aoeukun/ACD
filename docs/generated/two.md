# My Module

This module provides a simple way to print a greeting message to the user.

## Functions

### `greet(name)`

* `name`: The name of the person to greet.

Print a greeting message to the user with the given `name`.

**Usage:**
```python
from my_module import greet

greet("Alice")
# Output: "Hello, Alice!"
```
