### `input` Function

The `input` function in Python is used to get input from the user. It takes a prompt as an argument and displays it on the screen before waiting for the user to enter a value. The value entered by the user will be returned as a string.

Here's an example of how to use the `input` function:
```python
name = input("What is your name? ")
print("Hello, " + name + "!")
```
In this code, the `input` function is called with the prompt "What is your name?" as an argument. The user will be asked to enter their name and the value entered will be stored in the variable `name`. The `print` statement then prints a message greeting the user by their name.

### `print` Function

The `print` function in Python is used to print output to the screen. It takes any number of arguments as input and outputs them to the console, separated by spaces. The `print` function can also be used to print newlines using the escape sequence `\n`.

Here's an example of how to use the `print` function:
```python
name = input("What is your name? ")
print("Hello, " + name + "!")
```
In this code, the `print` function is used to print a message greeting the user by their name. The `input` function is called with the prompt "What is your name?" as an argument and the value entered by the user will be stored in the variable `name`.
