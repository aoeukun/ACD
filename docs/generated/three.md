# Python Program to Check Even or Odd

This program asks the user for a number and checks if it is even or odd. The program uses the modulo operator (`%`) to determine whether the number is even or odd. If the number is even, it prints "The number is even." Otherwise, it prints "The number is odd."

## Arguments

* `num`: The user-inputted number to check for evenness or oddness.

## Usage Example

Here is an example of how the user might use this program:
```
Enter a number: 42
The number is even.
```
Or, if the user enters an odd number:
```
Enter a number: 37
The number is odd.
```
Note that the `input()` function is used to prompt the user for input and retrieve it as a string. The `int()` function is then called on this string to convert it to an integer before using it in the modulo operator.
