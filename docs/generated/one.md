### add() function

The `add()` function takes two arguments of type `int` or `float`, and returns their sum.

**Inputs:**

* `a`: The first number to be added.
* `b`: The second number to be added.

**Output:** The sum of `a` and `b`.

**Usage example:**
```python
result = add(3, 5)
print(result) # Output: 8
```
